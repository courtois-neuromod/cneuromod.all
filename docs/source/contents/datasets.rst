Datasets
========

The CNeuroMod database currently includes the following experimental paradigms.
Each dataset page describes the experimental design, available assets, and how to cite the data.

.. tip::

   Granular, run-by-run availability of every asset — raw BOLD and physiology, fMRIPrep,
   tSNR maps, PhysPrep and timeseries — and which release storage holds it is documented
   in the `release dashboard <https://stats.cneuromod.ca>`_, regenerated from the
   `statistics pipeline <https://github.com/courtois-neuromod/cneuromod.all.statistics>`_.
